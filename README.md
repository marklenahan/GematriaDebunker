# Mark's Simple Gematria Debunker

A set of JavaScript tools for scoring words using alphabetic letter values (A=1, B=2, … Z=26), counting how many 
lexicon word combinations share a given total score, and generating random examples of those combinations.

Gematria is the practice of assigning numeric values to letters and words, then claiming that words or phrases with
equal scores have a hidden mystical connection. This tool lets you quickly find how many random word combinations
share any given score — typically millions or billions — demonstrating that score matches are numerically inevitable
rather than meaningful.

For more details on files, algorithms, node/web version, chaching, etc. please see [Gematria.md](Gematria.md)

There may be a live version running here: [https://gematriadebunker.onrender.com/](https://gematriadebunker.onrender.com/)

## Running local webserver
Install ExpressJS web framework if needed:
```
npm install express
```
Start the web server locally:
```
node server.js
```
Browse to the local web server to see the UX:
(http://localhost:3000/)
